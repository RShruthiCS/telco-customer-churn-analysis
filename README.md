# Telco Customer Churn Analysis

## Overview
This project analyzes customer data from a fictional telecom company to identify
the key factors that drive customer churn. Using PostgreSQL for data cleaning
and analysis, and Tableau for visualization, the goal is to understand which
customer segments are most likely to leave and recommend where the company
should focus retention efforts.

**Status: In progress.** Data cleaning and feature engineering are complete;
churn analysis and the Tableau dashboard are in progress.


## Data
Source: [Telco Customer Churn dataset](https://www.kaggle.com/blastchar/telco-customer-churn) (Kaggle, originally from IBM sample data).
7,043 customer records with demographic, account, and service information.

## Tools
- **PostgreSQL** for data cleaning, transformation, and analysis
- **Tableau** for building the interactive dashboard
- **Git/GitHub** for version control
